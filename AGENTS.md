# AGENTS.md — rss-ai

## Что это
Веб-приложение «AI News»: берёт RSS-ленту Wired об ИИ (по умолчанию `https://www.wired.com/feed/tag/ai/latest/rss`),
переводит заголовки и описания на русский и отдаёт страницу + JSON. Учебный демо-проект в репозитории
`silvegeno/test`, рабочая ветка `feature/rss-ai-news`.

Актуально на 23.11.2026: публичный лендинг и лента открыты без регистрации. Назначение лендинга —
показать RSS-пример для сайта или компании; кнопка демо ведёт на `/app/`.

## Стек
- Python 3.14, FastAPI + Uvicorn, feedparser 6.x, `translate` (неофициальный клиент Microsoft Translator).
- Фронтенд — чистый HTML/CSS/JS без сборки: `web/index.html`, `static/app.js`, `static/styles.css`.
- Контейнер: `python:3.14-slim`, пользователь 10001, read-only rootfs, tmpfs `/tmp` 16 МБ, `cap_drop: ALL`.
- CI (`.github/workflows/ci.yml`): unittest, py_compile, `docker build` на push в `feature/rss-ai-news` и на PR в `main`.

## Структура
```
app.py                  FastAPI: GET / (страница), /health, /api/news?limit=1..10; кэш 15 минут, общий Lock
rss_news.py             parse_rss(), translate_to_ru(), print_rss(); CLI-режим запускается напрямую
web/index.html          единственная страница интерфейса
static/app.js           fetch /api/news, рендер карточек, экранирование через textContent
static/styles.css       оформление
tests/test_rss_news.py  разбор локального сэмпла RSS, без сети
Dockerfile, docker-compose.yml, .dockerignore, .env.example
```

## Запуск
```bash
# локально, без Docker
.venv/Scripts/python.exe -m uvicorn app:app --reload --host 127.0.0.1 --port 8000

# локально, Docker (порт 8140)
docker compose up -d --build && docker compose ps
curl -s http://127.0.0.1:8140/health
curl -s "http://127.0.0.1:8140/api/news?limit=2"

# проверки
.venv/Scripts/python.exe -m unittest discover -s . -p "test_*.py" -v
.venv/Scripts/python.exe -m py_compile rss_news.py app.py
```

- 23.11.2026 — лента отдавала 502 «Лента или сервис перевода временно недоступны». Причина: провайдер
  перевода MyMemory (бесплатный, без ключа) исчерпал суточную квоту и отвечал 429; лента Wired при этом
  читалась нормально. Квоту выжгли частые обновления и пересоздания контейнера: переводы не сохранялись,
  и каждый рестарт переводил 10 новостей × 2 поля заново. Исправлено: `translate_to_ru` кеширует переводы
  на диск (`data/translation-cache.json`, том `./data:/app/data` в compose), при отказе провайдера лента
  отдаётся с оригинальным текстом и `translated: false`, перебор провайдера прекращается после первой
  ошибки, `/api/news` больше не отвечает 502 из-за перевода и возвращает `translation_available`,
  лента без перевода кешируется на 10 минут вместо 15, в интерфейсе появилось предупреждение
  «Перевод временно недоступен». Тесты: `tests/test_translate_fallback.py` (откат, кеш, остановка после
  первой ошибки). Проверено на живом сайте: 5 карточек, предупреждение видно, ошибки нет.
- 23.11.2026 — с лендинга и из `llms.txt` убрано упоминание Microsoft Translator: фактический провайдер —
  MyMemory, название в тексте было неверным.
