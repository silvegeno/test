git init - создание репы локально
git add . - застэйджить все файлы (подготовить к коммиту)
git commit -m “[напишите что сделали]”  - отправить коммит (все еще локально)
git remote add origin https://github.com/silvegeno/test.git - привязать локальную репу к удаленной
git push - отправить файлы на удаленную репу
git push --set-upstream origin master - для первого пуша (скопируйте что просит гит)

git clone <name> - загрузить репозиторий из Github
git pull - загрузить из репозитория на локальный компьютер
