## Вариант 1 — репозиторий на GitHub уже создан с README

Самый простой путь — сначала скачать репозиторий, чтобы локальная папка и GitHub начинали с одной истории:

```powershell
git clone https://github.com/silvegeno/test.git
cd test
```

Положите файлы проекта в эту папку, затем сохраните и отправьте их:

```powershell
git add .
git commit -m "Добавил файлы проекта"
git push
```

## Вариант 2 — проект уже находится в локальной папке

При создании репозитория на GitHub не добавляйте README, лицензию или `.gitignore`. Тогда удалённый репозиторий будет пустым, и его можно связать с уже существующей локальной историей:

```powershell
git init
git add .
git commit -m "Первый коммит"
git branch -M main
git remote add origin https://github.com/silvegeno/test.git
git push -u origin main
```

Если на GitHub уже создан README (или другой коммит), истории локальной папки и GitHub начинаются независимо. Обычный `git push` отклоняется, потому что удалённая ветка содержит коммит, которого нет локально. Объедините истории:

```powershell
git remote add origin https://github.com/silvegeno/test.git
git branch -M main
git pull --no-rebase origin main --allow-unrelated-histories
git push -u origin main
```

Эта команда `pull` нужна только когда локальный репозиторий и репозиторий на GitHub уже созданы отдельно и оба содержат коммиты. Если возникнут конфликты, сначала разрешите их, затем выполните `git add .`, `git commit` и `git push`.

## Обычная работа после первой отправки

После изменений в файлах:

```powershell
git add .
git commit -m "Кратко: что изменил"
git push
```

Первый `git push -u origin main` запоминает, куда отправлять текущую ветку. Поэтому позже обычно достаточно `git push`.

## Как узнать имя ветки и адрес репозитория

```powershell
git branch --show-current
git remote -v
git status
```

`git init` создаёт начальную ветку с именем из настроек Git. Это может быть `master` или `main`; `git branch -M main` переименовывает текущую ветку в `main`.

## Если проект ещё не скачан на этот компьютер

```powershell
git clone https://github.com/silvegeno/test.git
cd test
```

Чтобы получить более свежие изменения из GitHub в уже клонированный проект:

```powershell
git pull
```

## Термины

- `git init` — начать вести историю проекта локально.
- `git add .` — подготовить изменения к коммиту.
- `git commit -m "..."` — сохранить подготовленные изменения в локальной истории.
- `git remote add origin URL` — указать адрес удалённого репозитория.
- `git push` — отправить коммиты на GitHub.
- `git pull` — получить изменения с GitHub в текущую ветку.
